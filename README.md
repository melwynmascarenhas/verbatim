# Verbatim — Everyday Quotes & Wisdom

A web application for exploring and sharing verbatim thoughts, everyday wisdom, and unscripted lines.

## 🛠 Tech Stack

- **Frontend:** React 19 + React Router 7
- **Build Tool:** Vite
- **Backend:** Firebase (Authentication & Firestore)
- **Styling:** CSS Modules + Global CSS

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
